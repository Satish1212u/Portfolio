# Satish Gupta — Portfolio

A modern, responsive personal portfolio built with React.js, showcasing my skills, projects, services, and experience as a web developer.

## ✨ Features

- Responsive modern UI
- Dark / Light mode
- Smooth animations and transitions
- Projects showcase
- Skills and technologies
- Services section
- Contact form with EmailJS
- Email notifications for contact form submissions
- Phone and WhatsApp contact
- Real-time form validation
- Mobile-friendly design

## 🛠️ Tech Stack

- React.js
- TypeScript
- Tailwind CSS
- Framer Motion
- React Icons
- EmailJS
- Vite

## 💼 Services

- Website Development
- AI Automation
- AI Chatbots
- UI/UX Design
- Freelance / Development Work
- Website Maintenance & Support

## 📩 Contact

Visitors can contact me directly through the portfolio contact form.

The form collects:

- Name
- Email
- Project Type
- Phone / WhatsApp Number
- Message

Submissions are delivered directly to my email using EmailJS.
